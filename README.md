# Developer Portfolio 🌐

A responsive developer portfolio website built using HTML, CSS, and JavaScript. Designed to showcase a developer's skills, projects, and experience with a clean interface and light and dark mode support.

## 🔗 Live Demo

🚀 **Live Website:** [View Portfolio](https://mohitrw.github.io/developer-portfolio/)

## ✨ Features

- 🌗 **Light & Dark Mode** — Switch between light and dark themes.
- 💻 **Developer Portfolio UI** — A modern interface designed for a software engineer and web developer.
- 📱 **Responsive Design** — Layout designed to work across different screen sizes.
- 🎨 **Clean Interface** — Simple and visually appealing design.
- ⚡ **Interactive Elements** — JavaScript-powered interactions.

## 🛠️ Built With

- **HTML5** — Website structure.
- **CSS3** — Styling, layouts, and responsive design.
- **JavaScript** — Theme switching and interactive functionality.
